Codex es el agente de código de OpenAI. Funciona como CLI, extensión de IDE, modo de la app de escritorio de ChatGPT y servicio web, y todos inician sesión con tu cuenta de ChatGPT. El centro de ayuda de OpenAI dice que Codex "está incluido en todos los planes de ChatGPT, Free y Go incluidos", con límites que varían por plan y se cuentan en una ventana de cinco horas y otra semanal, compartidas con las demás funciones agénticas de tu plan.

## Instalar en Windows

La documentación de OpenAI da la instalación en Windows como una línea de PowerShell:

```powershell
irm https://chatgpt.com/codex/install.ps1 | iex
```

La forma documentada la envuelve en `powershell -ExecutionPolicy ByPass -c "…"` para poder lanzarla desde cualquier shell; dentro de PowerShell la línea de arriba es lo mismo. También hay `npm install -g @openai/codex` si ya usas Node.

## Instalar en macOS

El instalador independiente:

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

O `brew install --cask codex` con Homebrew, o el paquete de npm. El mismo comando actualiza una instalación existente.

## Iniciar sesión

Abre una carpeta de proyecto y ejecuta:

```bash
codex
```

La primera vez, Codex ofrece **Sign in with ChatGPT** y abre el navegador. `codex login` hace ese paso por sí solo, y es lo que el asistente de Tokendial ejecuta tras instalar. Ya dentro, `/status` en Codex muestra tus ventanas y sus reinicios.

## Qué lee Tokendial

Codex guarda la sesión de ChatGPT que obtuvo en un archivo, igual en los dos sistemas:

- Windows y macOS: `~/.codex/auth.json`

Tokendial lo lee en solo lectura y nunca lo refresca ni lo escribe. El token de identidad de dentro lleva tu correo y tipo de plan, que es lo que muestra la línea de cuenta bajo el dial. Codex informa de una ventana principal y una secundaria; el dial muestra la más apurada y la tarjeta lista las dos con su hora de reinicio.

Una segunda cuenta de ChatGPT es un segundo `CODEX_HOME`. Ejecuta Codex una vez con `CODEX_HOME=~/.codex-work` y ese perfil aparece como dial propio, "Codex (work)", con sus propias ventanas.

## O deja que Tokendial lo haga

<Figure src={rows} alt="Tres filas de proveedor en los ajustes de Tokendial, cada una con un botón Instalar y los pasos Instalar, Iniciar sesión, Listo" caption="Un proveedor cuya herramienta falta muestra los tres pasos y un botón Instalar." ours="una captura de Tokendial 0.1.0 en Windows" locale="es" />

En los ajustes de Tokendial la fila de Codex muestra **Instalar → Iniciar sesión → Listo** mientras falte la CLI. Pulsa **Instalar**, revisa el comando, pulsa **Ejecutar**: corre en una terminal visible, `codex login` sigue en la misma ventana y el dial se conecta cuando llega la credencial. Nada se ejecuta hasta que pulsas el botón.

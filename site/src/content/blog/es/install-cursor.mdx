Cursor es un editor con IA más que una herramienta de terminal: una app de escritorio derivada de VS Code con un agente integrado. Su documentación da un solo camino, "descarga Cursor, abre la app e inicia sesión", con instaladores nativos para macOS 12 o posterior y Windows 10 o posterior. Pro, Pro Plus y Ultra incluyen dos pools de consumo, uno para los modelos propios de Cursor y otro para modelos de terceros a precio de API, y los dos se reinician con tu ciclo de facturación mensual.

## Instalar en Windows

La página de descargas en [cursor.com/downloads](https://cursor.com/downloads) tiene el `.exe`. Si prefieres el gestor de paquetes, el manifiesto comunitario de WinGet instala la misma versión:

```powershell
winget install Anysphere.Cursor
```

`winget` viene con Windows 11; en Windows 10 llega con "Instalador de aplicaciones" desde la Microsoft Store.

## Instalar en macOS

El `.dmg` de la misma página de descargas, o el cask de Homebrew:

```bash
brew install --cask cursor
```

## Iniciar sesión

Abre Cursor e inicia sesión desde la pantalla de bienvenida con tu cuenta de Cursor. No hay ningún comando que ejecutar. Elige una carpeta y el agente está listo con Ctrl I (Cmd I en macOS).

## Qué lee Tokendial

Cursor guarda la sesión del editor en su base de datos de estado global, y Tokendial reutiliza esa sesión contra cursor.com, en solo lectura:

- Windows: `%APPDATA%/Cursor/User/globalStorage/state.vscdb`
- macOS: `~/Library/Application Support/Cursor/User/globalStorage/state.vscdb`

La base de datos está en modo *write-ahead* mientras el editor corre, así que Tokendial la abre de manera que ve el token actual y no uno de un punto de control anterior. La tarjeta muestra el **consumo incluido** como titular, más el consumo de API y el gasto bajo demanda, cada uno con el reinicio de tu ciclo de facturación. No se escribe nada de vuelta y el token nunca se refresca ni se copia.

## O deja que Tokendial lo haga

<Figure src={rows} alt="Tres filas de proveedor en los ajustes de Tokendial, cada una con un botón Instalar y los pasos Instalar, Iniciar sesión, Listo" caption="La fila de Cursor mientras falta la app." ours="una captura de Tokendial 0.1.0 en Windows" locale="es" />

Como Cursor es una app, el asistente cambia un poco respecto a las herramientas de terminal. En los ajustes de Tokendial la fila de Cursor muestra **Instalar → Iniciar sesión → Listo**; pulsa **Instalar**, revisa el comando de WinGet o Homebrew, pulsa **Ejecutar** y el instalador corre en una terminal visible. Después abre Cursor e inicia sesión dentro de la app: el dial se conecta en cuanto el editor tiene sesión. Nada se ejecuta hasta que pulsas el botón.

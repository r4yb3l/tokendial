GitHub Copilot CLI es el agente de terminal de la familia Copilot, y la documentación de GitHub dice que "está disponible con todos los planes de Copilot", los gratuitos incluidos. Desde junio de 2026 los planes de pago miden el uso en créditos de IA de GitHub que se rellenan el día 1 de cada mes, como explica [Cómo te miden los planes](/es/blog/how-plans-meter-you); si recibes Copilot a través de una organización, su administrador tiene que dejar activada la política de Copilot CLI.

## Instalar en Windows

GitHub documenta WinGet como la vía en Windows, con PowerShell 6 o posterior como requisito:

```powershell
winget install GitHub.Copilot
```

El asistente de Tokendial añade los dos indicadores `--accept-…-agreements` para que el comando no se pare a preguntar. `npm install -g @github/copilot` (Node 22 o posterior) funciona en todas las plataformas.

## Instalar en macOS

Homebrew:

```bash
brew install --cask copilot-cli
```

O el script de instalación de GitHub, que también cubre Linux:

```bash
curl -fsSL https://gh.io/copilot-install | bash
```

## Iniciar sesión

Arranca la CLI:

```bash
copilot
```

Si no has iniciado sesión en GitHub, la documentación dice que "se te pedirá usar el comando `/login`"; síguelo y termina en el navegador. Un token de acceso personal de grano fino con el permiso *Copilot Requests*, exportado como `COPILOT_GITHUB_TOKEN`, es la alternativa documentada para máquinas sin navegador.

## Qué lee Tokendial

Las herramientas de Copilot guardan su token OAuth de GitHub en un archivo con una entrada por app que inició sesión:

- Windows: `%LOCALAPPDATA%/github-copilot/apps.json`
- macOS: `~/.config/github-copilot/apps.json`

Tokendial lo lee en solo lectura, recurre al `hosts.json` antiguo y, como último recurso, al token de la propia CLI de GitHub, y pregunta al endpoint de uso que lee la barra de estado del editor. Un 403 de ese endpoint significa que la cuenta no tiene asiento de Copilot, y la fila lo dice. La tarjeta lista las ventanas que GitHub publica para tu plan, cada una con su reinicio.

## O deja que Tokendial lo haga

<Figure src={rows} alt="Tres filas de proveedor en los ajustes de Tokendial, cada una con un botón Instalar y los pasos Instalar, Iniciar sesión, Listo" caption="La fila de GitHub Copilot mientras falta la CLI." ours="una captura de Tokendial 0.1.0 en Windows" locale="es" />

En los ajustes de Tokendial la fila de Copilot muestra **Instalar → Iniciar sesión → Listo**. Pulsa **Instalar**, revisa el comando de WinGet o el script, pulsa **Ejecutar**: corre en una terminal visible, la CLI se abre para `/login` en la misma ventana y el dial se conecta cuando aparece el archivo de token. Nada se ejecuta hasta que pulsas el botón.

Claude Code es el agente de código de Anthropic para la terminal, con extensiones para VS Code y JetBrains y una app de escritorio. Viene con los planes Claude Pro, Max, Team y Enterprise, y sus límites son los que describe [Cómo leer tus límites de Claude Code](/es/blog/read-your-claude-code-limits): una ventana de sesión deslizante de cinco horas y una semanal, compartidas con el chat de Claude de la misma cuenta, más ventanas por modelo en algunos planes.

La documentación de Anthropic recomienda el instalador nativo. Homebrew y WinGet también están documentados; el nativo es el que se actualiza solo en segundo plano.

## Instalar en Windows

Abre PowerShell y ejecuta el comando que publica Anthropic:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Si ves *"The token '&&' is not a valid statement separator"*, estás en PowerShell ejecutando un comando de CMD, o al revés. Anthropic recomienda además Git para Windows para que Claude Code pueda usar su herramienta Bash; sin él, el agente usa PowerShell para los comandos.

## Instalar en macOS

En Terminal:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

O con Homebrew, que no se autoactualiza: `brew install --cask claude-code`.

## Iniciar sesión

Ejecuta la herramienta una vez:

```bash
claude
```

Claude Code te manda al navegador a iniciar sesión con tu cuenta de Claude y vuelve con la sesión abierta. Si tienes una `ANTHROPIC_API_KEY` en el entorno, Claude Code la usará en lugar de tu suscripción y te cobrará a precio de API; quítala si quieres tu plan.

## Qué lee Tokendial

Tras el inicio de sesión, Claude Code guarda un token en tu equipo y Tokendial lo lee ahí, en solo lectura, sin refrescarlo, escribirlo ni copiarlo:

- Windows: `~/.claude/.credentials.json`
- macOS: el elemento del llavero `Claude Code-credentials`

Con ese token Tokendial pregunta al mismo endpoint de uso que consulta `/usage` dentro de Claude Code. El dial muestra la ventana de **sesión actual**; pasa el cursor para ver la semanal, las ventanas por modelo si las hay y la hora de cada reinicio.

Una segunda cuenta es un segundo directorio de configuración. Si ejecutas Claude Code con `CLAUDE_CONFIG_DIR=~/.claude-work`, ese perfil aparece en su propio dial como "Claude Code (work)".

## O deja que Tokendial lo haga

<Figure src={rows} alt="Tres filas de proveedor en los ajustes de Tokendial, cada una con un botón Instalar y los pasos Instalar, Iniciar sesión, Listo" caption="Los proveedores cuya herramienta falta muestran los tres pasos y un botón Instalar." ours="una captura de Tokendial 0.1.0 en Windows" locale="es" />

Abre los ajustes de Tokendial. Un proveedor cuya herramienta no está instalada muestra **Instalar → Iniciar sesión → Listo**. Tokendial enseña este mismo comando de instalación, pulsas **Ejecutar**, corre en una ventana de terminal visible y el inicio de sesión sigue en la misma terminal. El dial se conecta en cuanto aparece la credencial. Nada se ejecuta hasta que pulsas el botón.

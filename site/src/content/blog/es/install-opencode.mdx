OpenCode es un agente de código abierto para la terminal que funciona con más de 75 proveedores de modelos. Tokendial mide uno de ellos: **OpenCode Go**, la suscripción de 10 $ al mes a una lista seleccionada de modelos abiertos, cuya documentación expresa sus límites en dinero, 12 $ de uso por cinco horas, 30 $ por semana y 60 $ al mes. Las claves de otros proveedores que añadas a OpenCode nunca se leen.

## Instalar en Windows

La documentación de OpenCode recomienda WSL en Windows para la mejor experiencia, y lista Chocolatey, Scoop y npm para instalaciones nativas. El manifiesto comunitario de WinGet lleva la misma versión:

```powershell
winget install SST.opencode
```

`npm install -g opencode-ai`, `choco install opencode` y `scoop install opencode` son las alternativas documentadas.

## Instalar en macOS

El script de instalación:

```bash
curl -fsSL https://opencode.ai/install | bash
```

O el tap de Homebrew del proyecto, que la documentación recomienda frente a la fórmula central por actualizarse antes: `brew install anomalyco/tap/opencode`.

## Iniciar sesión

Suscríbete a Go en opencode.ai, copia tu clave de API y conecta el proveedor. Dentro de la TUI:

```
/connect
```

Elige **OpenCode Go** y pega la clave. El mismo paso desde la shell es `opencode auth login`, que es lo que el asistente de Tokendial ejecuta tras instalar. Ejecuta `/models` para ver los modelos que te da Go.

## Qué lee Tokendial

OpenCode guarda las credenciales de proveedor en un archivo:

- macOS: `~/.local/share/opencode/auth.json`
- Windows: la misma ruta bajo tu perfil de usuario; OpenCode puede usar también `%APPDATA%/opencode/auth.json`, y Tokendial mira ahí también

Solo se usa la entrada `opencode-go`. Cualquier otra entrada de ese archivo es la clave de otro fabricante y nunca se reclama. Con la clave de Go, Tokendial pregunta al endpoint de uso de Go y muestra el **límite de 5 horas** en el dial, con los límites semanal y mensual en la tarjeta.

## O deja que Tokendial lo haga

<Figure src={rows} alt="Tres filas de proveedor en los ajustes de Tokendial, cada una con un botón Instalar y los pasos Instalar, Iniciar sesión, Listo" caption="Una fila de proveedor mientras falta su CLI." ours="una captura de Tokendial 0.1.0 en Windows" locale="es" />

En los ajustes de Tokendial la fila de OpenCode muestra **Instalar → Iniciar sesión → Listo**. Pulsa **Instalar**, revisa el comando de WinGet o el script, pulsa **Ejecutar**: el instalador corre en una terminal visible, `opencode auth login` sigue en la misma ventana y el dial se conecta cuando la entrada de Go aparece en el archivo. Nada se ejecuta hasta que pulsas el botón.

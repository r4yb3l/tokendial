OpenCode is an open-source coding agent for the terminal that works with more than 75 model providers. Tokendial meters one of them: **OpenCode Go**, the $10-a-month subscription to a curated list of open models, whose documentation states its limits in money, $12 of usage per five hours, $30 per week and $60 per month. Keys for other providers you add to OpenCode are never read.

## Install on Windows

OpenCode's documentation recommends WSL on Windows for the best experience, and lists Chocolatey, Scoop and npm for native installs. The WinGet community manifest carries the same release:

```powershell
winget install SST.opencode
```

`npm install -g opencode-ai`, `choco install opencode` and `scoop install opencode` are the documented alternatives.

## Install on macOS

The install script:

```bash
curl -fsSL https://opencode.ai/install | bash
```

Or the project's Homebrew tap, which the documentation recommends over the core formula for faster updates: `brew install anomalyco/tap/opencode`.

## Sign in

Subscribe to Go at opencode.ai, copy your API key, then connect the provider. Inside the TUI:

```
/connect
```

Select **OpenCode Go** and paste the key. The same step from the shell is `opencode auth login`, which is what Tokendial's assistant runs after installing. Run `/models` to see the models Go gives you.

## What Tokendial reads

OpenCode stores provider credentials in one file:

- macOS: `~/.local/share/opencode/auth.json`
- Windows: the same path under your user profile; OpenCode may also use `%APPDATA%/opencode/auth.json`, and Tokendial checks there too

Only the `opencode-go` entry is used. Every other entry in that file is another vendor's key and is never claimed. With the Go key Tokendial asks the Go usage endpoint and shows the **5-hour limit** on the dial, with the weekly and monthly limits on the card.

## Or let Tokendial do it

<Figure src={rows} alt="Three provider rows in Tokendial's settings, each with an Install button and the steps Install, Sign in, Ready" caption="A provider row while its CLI is missing. Interface shown in Spanish." ours="a screenshot of Tokendial 0.1.0 on Windows" locale="en" />

In Tokendial's settings the OpenCode row shows **Install → Sign in → Ready**. Press **Install**, review the WinGet or script command, press **Run**: the installer runs in a visible terminal, `opencode auth login` follows in the same window, and the dial connects when the Go entry appears in the file. Nothing runs until you press the button.

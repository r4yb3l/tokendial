Antigravity is Google's agent-first development environment: a desktop IDE, extensions for VS Code, JetBrains, Zed and Xcode, and a CLI, all signed in with a Google account. Since 18 June 2026 it is also where Google sends individual Gemini CLI users. Quota comes as a baseline per plan: on Google AI Pro and Ultra it is "refreshed every five hours" alongside a weekly limit, on free accounts it refreshes weekly, and the documentation is candid that the limits "are correlated with the amount of work done by the agent".

## Install on Windows

Google's download page at [antigravity.google/download](https://antigravity.google/download) has installers for x64 and ARM64 on Windows 10 (64-bit) and later. The Windows Package Manager fetches the same installer:

```powershell
winget install Google.Antigravity
```

## Install on macOS

The download page has Apple Silicon and Intel builds for macOS 12 (Monterey) and later, or use the Homebrew cask:

```bash
brew install --cask antigravity
```

## Sign in

Open Antigravity and sign in with your Google account inside the app. Nothing else is needed; the CLI, if you install it, shares the sign-in. Inside the CLI, `/usage` (alias `/quota`) opens the panel with your remaining quota per model.

## What Tokendial reads

Antigravity keeps its token in the system credential store, and Tokendial reads it there, read-only:

- Windows: the Credential Manager entry `gemini:antigravity`
- macOS: the Keychain item `gemini`

With it Tokendial asks the same quota endpoints the IDE asks and reads the IDE's own language server for activity. The dial shows the weekly quota of the tightest model group; the card lists every group with its reset. Nothing is refreshed, written or copied.

## Or let Tokendial do it

<Figure src={rows} alt="Three provider rows in Tokendial's settings, each with an Install button and the steps Install, Sign in, Ready" caption="Antigravity's row while the app is missing. Interface shown in Spanish." ours="a screenshot of Tokendial 0.1.0 on Windows" locale="en" />

Antigravity is an app, so the assistant installs and then hands over to you. In Tokendial's settings the row shows **Install → Sign in → Ready**; press **Install**, review the WinGet or Homebrew command, press **Run**, and the installer runs in a visible terminal. Then open Antigravity and sign in inside the app; the dial connects as soon as the credential exists. Nothing runs until you press the button.

Claude Code is Anthropic's coding agent for the terminal, with extensions for VS Code and JetBrains and a desktop app. It comes with the Claude Pro, Max, Team and Enterprise plans, and its limits are the ones described in [How to read your Claude Code limits](/blog/read-your-claude-code-limits): a rolling five-hour session window and a weekly window, shared with the Claude chat on the same account, plus per-model windows on some plans.

Anthropic's documentation recommends the native installer. Homebrew and WinGet are also documented; the native install is the one that updates itself in the background.

## Install on Windows

Open PowerShell and run the command Anthropic publishes:

```powershell
irm https://claude.ai/install.ps1 | iex
```

If you see *"The token '&&' is not a valid statement separator"*, you are in PowerShell running a CMD command, and vice versa. Anthropic also recommends Git for Windows so that Claude Code can use its Bash tool; without it, the agent uses PowerShell for shell commands.

## Install on macOS

In Terminal:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Or with Homebrew, which does not auto-update: `brew install --cask claude-code`.

## Sign in

Run the tool once:

```bash
claude
```

Claude Code sends you to the browser to sign in with your Claude account and comes back logged in. If you have an `ANTHROPIC_API_KEY` in your environment, Claude Code will use that instead of your subscription and bill you at API rates; unset it if you want your plan.

## What Tokendial reads

After sign-in, Claude Code keeps a token on your computer and Tokendial reads it there, read-only, never refreshing, writing or copying it:

- Windows: `~/.claude/.credentials.json`
- macOS: the Keychain item `Claude Code-credentials`

With that token Tokendial asks the same usage endpoint that `/usage` inside Claude Code asks. The dial shows the **current session** window; hover it for the weekly window, any per-model windows and each reset time.

A second account is a second configuration directory. If you run Claude Code with `CLAUDE_CONFIG_DIR=~/.claude-work`, that profile appears on its own dial as "Claude Code (work)".

## Or let Tokendial do it

Open Tokendial's settings. A provider whose tool is not installed shows **Install → Sign in → Ready**. Tokendial displays this same install command, you press **Run**, it runs in a visible terminal window, and the sign-in follows in the same terminal. The dial connects the moment the credential appears. Nothing runs until you press the button.

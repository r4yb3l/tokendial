Grok Build is xAI's coding CLI. It signs in with your xAI account and meters usage per window.

Tokendial reads the token the CLI stores after `grok login` and asks xAI for the current usage.

## Install on Windows

Open PowerShell and run the command xAI publishes:

```powershell
irm https://x.ai/cli/install.ps1 | iex
```

## Install on macOS

In Terminal, run the command xAI publishes:

```bash
curl -fsSL https://x.ai/cli/install.sh | bash
```

## Sign in

Once installed, sign in with the tool itself:

```bash
grok login
```

Grok opens the browser to sign in with your xAI account.

## What Tokendial reads

After the sign-in, Grok keeps a credential on your computer. Tokendial reads it there, read-only, and never writes, refreshes or copies it:

- Windows: `~/.grok/auth.json`
- macOS: `~/.grok/auth.json`

The dial shows the **current window**. Hover it to see the other windows and when each one resets.

## Or let Tokendial do it

If you would rather not touch a terminal, open Tokendial's settings: a provider whose tool is missing shows **Install → Sign in → Ready**. Tokendial shows this same command, you press **Run**, it runs in a visible terminal, and the dial connects the moment the sign-in lands.

Official documentation: [https://docs.x.ai/build/cli/reference](https://docs.x.ai/build/cli/reference).

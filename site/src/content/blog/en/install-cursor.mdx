Cursor is an AI editor rather than a terminal tool: a VS Code-derived desktop app with an agent built in. Its documentation gives one path, "download Cursor, open the app and sign in", with native installers for macOS 12 and later and Windows 10 and later. Pro, Pro Plus and Ultra include two usage pools, one for Cursor's own models and one for third-party models at API price, both of which reset with your monthly billing cycle.

## Install on Windows

The download page at [cursor.com/downloads](https://cursor.com/downloads) has the `.exe`. If you prefer the package manager, the community WinGet manifest installs the same build:

```powershell
winget install Anysphere.Cursor
```

`winget` ships with Windows 11; on Windows 10 it comes with "App Installer" from the Microsoft Store.

## Install on macOS

The `.dmg` from the same download page, or the Homebrew cask:

```bash
brew install --cask cursor
```

## Sign in

Open Cursor and sign in from the welcome screen with your Cursor account. There is no command to run. Pick a folder and the agent is ready under Ctrl I (Cmd I on macOS).

## What Tokendial reads

Cursor keeps the editor's session in its global state database, and Tokendial reuses that session against cursor.com, read-only:

- Windows: `%APPDATA%/Cursor/User/globalStorage/state.vscdb`
- macOS: `~/Library/Application Support/Cursor/User/globalStorage/state.vscdb`

The database is in write-ahead mode while the editor runs, so Tokendial opens it in a way that sees the current token rather than a checkpointed one. The card shows **Included usage** as the headline, plus API usage and on-demand spend, each with the reset of your billing cycle. Nothing is written back and the token is never refreshed or copied.

## Or let Tokendial do it

<Figure src={rows} alt="Three provider rows in Tokendial's settings, each with an Install button and the steps Install, Sign in, Ready" caption="Cursor's row while the app is missing. Interface shown in Spanish." ours="a screenshot of Tokendial 0.1.0 on Windows" locale="en" />

Because Cursor is an app, the assistant differs slightly from the CLI tools. In Tokendial's settings the Cursor row shows **Install → Sign in → Ready**; press **Install**, review the WinGet or Homebrew command, press **Run**, and the installer runs in a visible terminal. Then open Cursor and sign in inside the app: the dial connects as soon as the editor has a session. Nothing runs until you press the button.

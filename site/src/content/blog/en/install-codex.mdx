Codex is OpenAI's coding agent. It runs as a CLI, an IDE extension, a mode of the ChatGPT desktop app and a web service, and all of them sign in with your ChatGPT account. OpenAI's help centre says Codex "is included across ChatGPT plans, including Free and Go", with usage limits that vary by plan and are counted in a five-hour window and a weekly one, shared with the other agentic features of your plan.

## Install on Windows

OpenAI's documentation gives the Windows install as a PowerShell one-liner:

```powershell
irm https://chatgpt.com/codex/install.ps1 | iex
```

The documented form wraps it in `powershell -ExecutionPolicy ByPass -c "…"` so it can be run from any shell; inside PowerShell the line above is the same thing. There is also `npm install -g @openai/codex` if you already use Node.

## Install on macOS

The standalone installer:

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

Or `brew install --cask codex` with Homebrew, or the npm package. The same command updates an existing install.

## Sign in

Open a project folder and run:

```bash
codex
```

The first time, Codex offers **Sign in with ChatGPT** and opens the browser. `codex login` does the same step on its own, which is what Tokendial's assistant runs after installing. Once you are in, `/status` inside Codex shows your windows and their resets.

## What Tokendial reads

Codex stores the ChatGPT session it obtained in one file on both systems:

- Windows and macOS: `~/.codex/auth.json`

Tokendial reads it read-only and never refreshes or writes it. The identity token inside carries your email and plan type, which is what the account line under the dial shows. Codex reports a primary and a secondary window; the dial shows the tighter one and the card lists both with their reset times.

A second ChatGPT account is a second `CODEX_HOME`. Run Codex with `CODEX_HOME=~/.codex-work` once and that profile appears as its own dial, "Codex (work)", with its own windows.

## Or let Tokendial do it

In Tokendial's settings the Codex row shows **Install → Sign in → Ready** while the CLI is missing. Press **Install**, review the command, press **Run**: it executes in a visible terminal, `codex login` follows in the same window, and the dial connects when the credential lands. Nothing runs until you press the button.

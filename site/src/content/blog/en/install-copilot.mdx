GitHub Copilot CLI is the terminal agent of the Copilot family, and GitHub's documentation says it "is available with all Copilot plans", the free ones included. Since June 2026 paid plans meter usage in GitHub AI Credits that refill on the first of each month, as [How the plans meter you](/blog/how-plans-meter-you) explains; if you get Copilot through an organisation, its administrator has to leave the Copilot CLI policy enabled.

## Install on Windows

GitHub documents WinGet as the Windows route, with PowerShell 6 or later as a prerequisite:

```powershell
winget install GitHub.Copilot
```

Tokendial's assistant adds the two `--accept-…-agreements` flags so the command does not stop to ask. `npm install -g @github/copilot` (Node 22 or later) works on every platform.

## Install on macOS

Homebrew:

```bash
brew install --cask copilot-cli
```

Or GitHub's install script, which also covers Linux:

```bash
curl -fsSL https://gh.io/copilot-install | bash
```

## Sign in

Start the CLI:

```bash
copilot
```

If you are not signed in to GitHub, the documentation says you will be "prompted to use the `/login` slash command"; follow it and finish in the browser. A fine-grained personal access token with the *Copilot Requests* permission, exported as `COPILOT_GITHUB_TOKEN`, is the documented alternative for machines without a browser.

## What Tokendial reads

The Copilot tools keep their GitHub OAuth token in one file per signed-in app:

- Windows: `%LOCALAPPDATA%/github-copilot/apps.json`
- macOS: `~/.config/github-copilot/apps.json`

Tokendial reads it read-only, falls back to the older `hosts.json` and, as a last resort, to the GitHub CLI's own token, and asks the usage endpoint the editor status bar reads. A 403 from that endpoint means the account has no Copilot seat, and the row says so. The card lists the windows GitHub publishes for your plan, each with its reset.

## Or let Tokendial do it

<Figure src={rows} alt="Three provider rows in Tokendial's settings, each with an Install button and the steps Install, Sign in, Ready" caption="GitHub Copilot's row while the CLI is missing. Interface shown in Spanish." ours="a screenshot of Tokendial 0.1.0 on Windows" locale="en" />

In Tokendial's settings the Copilot row shows **Install → Sign in → Ready**. Press **Install**, review the WinGet or script command, press **Run**: it runs in a visible terminal, the CLI opens for `/login` in the same window, and the dial connects when the token file appears. Nothing runs until you press the button.
